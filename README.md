# experiment/01-code-cloning

## 실험 목적
국제화를 고려하지 않고, 언어별로 HTML 템플릿을 복사해서 현지화된 페이지를 제공하는 구조를 구현해 본다.

## 구현 방식
- 언어별 템플릿 디렉토리 분리
  - `templates_ko/index.html`
  - `templates_en/index.html`
- `/ko`, `/en` 경로에 따라 각 언어별 화면 제공
- 글쓰기 화면 구성 요소:
  - 제목 입력
  - 내용 입력
  - 등록/제출 버튼

## 확인 방법
| 경로 | 결과 |
|------|------|
| `/ko` | 한국어 글쓰기 화면 |
| `/en` | 영어 글쓰기 화면 |

## 느낀 점 / 단점
- 언어가 추가될수록 템플릿 복사가 필요 → 코드 중복 심화
- 텍스트 수정 시 모든 언어 파일 동시 수정 필요
- 유지보수가 비효율적임
